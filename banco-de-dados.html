Banco de Dados

Sobre a matéria

A disciplina de Banco de Dados tem como objetivo ensinar a armazenar, organizar e consultar informações de maneira eficiente. Estudamos a modelagem de dados, tabelas, relacionamentos e a linguagem SQL, usada para inserir, alterar, excluir e buscar dados. Aprendemos também a importância da organização e da segurança das informações. Esse conhecimento é fundamental porque praticamente todos os sistemas, de redes sociais a lojas virtuais, dependem de bancos de dados para funcionar.
