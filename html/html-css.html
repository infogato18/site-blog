HTML/CSS

Sobre a matéria

A matéria de HTML e CSS é voltada para o desenvolvimento e a criação de páginas para a internet. Durante as aulas, aprendemos que o HTML é responsável pela estrutura e organização dos elementos de uma página, enquanto o CSS é utilizado para definir sua aparência. Com esses dois recursos, podemos criar páginas com textos, imagens, links, botões, menus e diferentes tipos de conteúdo.
No HTML, aprendemos a utilizar diferentes elementos e organizar corretamente as informações de uma página. Também trabalhamos com títulos, parágrafos, imagens, links, listas, formulários e outras estruturas importantes para a construção de sites. Dessa forma, conseguimos transformar uma ideia em uma página que pode ser visualizada pelo usuário.
Já no CSS, aprendemos a modificar a aparência das páginas. Podemos escolher cores, fontes, tamanhos, espaçamentos, bordas, sombras e posições dos elementos. Também podemos criar efeitos quando o usuário passa o mouse sobre um botão ou outro elemento da página. Isso permite criar sites mais organizados, modernos e agradáveis de utilizar.
Durante a disciplina, os alunos podem desenvolver projetos próprios para colocar os conhecimentos em prática. A criação de sites também permite trabalhar criatividade e organização, pois é necessário pensar tanto no conteúdo quanto na aparência e na facilidade de navegação.
Os conhecimentos de HTML e CSS são importantes para quem deseja continuar estudando desenvolvimento web, pois representam uma das bases para a criação de páginas e interfaces para a internet.
