Programação Web

Sobre a matéria

A disciplina de Programação Web tem como objetivo nos ensinar a criar sites e aplicações dinâmicas, que interagem com o usuário. Partindo do que aprendemos em HTML e CSS, estudamos como usar linguagens de programação para dar vida às páginas, com formulários, validações e conteúdo que muda conforme as ações de quem acessa. Também entendemos como funciona a comunicação entre o navegador e o servidor. A matéria é importante porque quase tudo o que usamos hoje está na web, e esse conhecimento abre portas para uma das áreas com mais oportunidades na tecnologia.
